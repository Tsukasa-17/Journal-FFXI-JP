# Japanese derivative changes

版番号: 日本語版で自分たちが大きく足したものはマイナー（0.x.0）。上流の取り込みや、訳・小さな修正はパッチ（0.x.x）。上流 0.3.4 の取り込みは jpver 0.2.1。CatsEye のクエスト追加は jpver 0.3.0。addon.version は 0.3.7、原作者は Kxteel。

2026-11-12 jpver 0.3.2:

上流の 0.3.5 から 0.3.7 までを取り込みました。

**本**
- ツールバーのメニューから、ガイド、キャンプ、メモ、名声を開けるようになりました。
- 進行中、ミッション、クエストのボタンは、開いているときと閉じているときで見た目が変わるようになりました。
- 手順が求めているアイテムを持っているとき、足りていれば緑の印、足りなければ持っている数と必要な数が表示されるようになりました。
- だいじなものも、手順に名前があれば同じ印の対象になりました。
- 報酬としてもらう品には、所持の印を付けません。
- 手順のアイテム名は、確認できた公式の日本語名で表示します。確認できない名前は英語のままです。
- 手順のアイテム名が日本語のときも、持っている数の印を表示します。
- 手順の数が「枚」「本」「匹」「通」で書かれているときも、持っている数と必要な数を表示します。

**メモ**
- タイトルとフォルダを付けたメモを、キャラクターをまたいで保存できるようになりました。
- フォルダに色を付けて、一覧で見分けられるようになりました。
- メモの窓は角をドラッグして大きさを変えられ、次に開いたときもその大きさです。

**トラッカー**
- 手順が求めているアイテムの印が、トラッカーの文にも出るようになりました。

**コンパス**
- 名声を教えてくれる人が近くにいると、コンパスに出るようになりました。
- 三国のゲートガードが近くにいると、ミッションの進み具合の絵付きでコンパスに出るようになりました。

**名声**
- 名声を教えてくれる人に話すと、その国の名声を覚えて、名声の窓に出せるようになりました。
- 名声の窓は角をドラッグして大きさを変えられ、次に開いたときもその大きさです。
- 話して確認した名声より高い名声が必要なクエストは、鍵の絵で出るようになりました。

**通知**
- 新しいクエストやミッションの通知と、完了したときの通知に、進み具合の絵が名前の左へ出るようになりました。

**ミッション**
- 自国のランクが足りないミッションは、鍵の絵で出るようになりました。
