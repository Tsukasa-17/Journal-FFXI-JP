Sounds of the alerts (optional).

Put your own files here, with these names:

  new_quest.wav         plays when a new quest appears
  new_mission.wav       plays when a new mission appears
  complete_quest.wav    plays when a quest is completed
  complete_mission.wav  plays when a mission is completed
  nearby_quest.wav      plays when you enter a zone with quests not active yet

If a file is missing that alert is silent and the chat says so once.
The sound can be turned off in the settings window (Alerts).
